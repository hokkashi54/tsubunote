# つぶノート — セットアップ手順

SNS風のひとりごとメモアプリです。データは Google ドライブの「アプリ専用の隠しフォルダ（appDataFolder）」に保存され、iPhone / Android / Windows で同期できます。費用はかかりません（GitHub・Google Cloud ともに無料枠で動きます）。

所要時間：初回のみ 20〜30 分。

---

## 1. アプリを公開する（GitHub Pages・無料）

1. https://github.com でアカウントを作成（持っていれば不要）
2. 右上「＋」→「New repository」
   - Repository name：`tsubunote`（好きな名前でOK）
   - **Public** を選択（無料の Pages は公開リポジトリが必要。公開されるのはアプリのプログラムだけで、メモの中身は一切含まれません）
   - 「Create repository」
3. 「uploading an existing file」をクリック → このフォルダの中身（`index.html`、`sw.js`、`manifest.webmanifest`、`icons` フォルダ）をまとめてドラッグ＆ドロップ →「Commit changes」
4. リポジトリの「Settings」→ 左メニュー「Pages」
   - Source：「Deploy from a branch」／ Branch：`main`・`/ (root)` →「Save」
5. 1〜2分後、`https://<あなたのユーザー名>.github.io/tsubunote/` で開けるようになります

> この URL を以下「アプリのURL」と呼びます。

---

## 2. Google ドライブ連携の設定（Google Cloud・無料）

1. https://console.cloud.google.com を開き、同期に使う Google アカウントでログイン
2. 上部のプロジェクト選択 →「新しいプロジェクト」→ 名前（例：tsubunote）→「作成」
3. 左上メニュー →「API とサービス」→「ライブラリ」→ **Google Drive API** を検索 →「有効にする」
4. 左上メニュー →「Google Auth Platform」（または「OAuth 同意画面」）→「開始」
   - アプリ名：つぶノート ／ サポートメール：自分のアドレス
   - 対象：**外部**
   - 連絡先：自分のアドレス →「作成」
5. 「対象（Audience）」→「テストユーザー」→「ユーザーを追加」→ **自分の Gmail アドレス**を追加
   - 公開ステータスは「テスト中」のままで大丈夫です（自分専用のため）
6. 「クライアント」→「クライアントを作成」
   - アプリケーションの種類：**ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元：`https://<ユーザー名>.github.io`
   - 承認済みのリダイレクト URI：`https://<ユーザー名>.github.io/tsubunote/`（末尾の `/` まで正確に）
   - 「作成」→ 表示された **クライアント ID**（`xxxx.apps.googleusercontent.com`）をコピー

> 正確な URI はアプリの「設定 → Google ドライブ同期」にも表示されます。そこからコピーするのが確実です。

---

## 3. アプリで接続する

1. アプリのURLを開く →（左上アイコンのメニュー or サイドバー）「設定」
2. 「OAuth クライアントID」にコピーした ID を貼り付け
3. 「Googleで接続」→ Google アカウントを選択
   - 「Google はこのアプリを確認していません」と出たら「続行」（自分で作ったアプリなので問題ありません）
   - ドライブへのアクセスを許可
4. 他の端末でも同じアプリのURLを開き、**同じクライアントID**を入れて接続すれば同期されます

---

## 4. 各端末にインストール

| 端末 | 手順 |
|---|---|
| iPhone / iPad | **Safari** でアプリのURLを開く → 共有ボタン →「ホーム画面に追加」 |
| Android | **Chrome** でアプリのURLを開く → ︙メニュー →「アプリをインストール」（または「ホーム画面に追加」） |
| Windows | **Edge** で開く → アドレスバー右の「アプリを使用できます」アイコン（または …→「アプリ」→「このサイトをアプリとしてインストール」）。Chrome でも可 |

インストール後はホーム画面／スタートメニューから普通のアプリのように起動できます（ブラウザのバーは出ません）。

---

## 同期のしくみ

- メモはまず端末内に保存され、オフラインでも使えます。接続中は変更から約2.5秒後に自動でドライブへ同期します。
- 起動時・アプリに戻った時・5分ごとにも同期します。
- Google のログイン有効期限は約1時間です。切れていると起動時に自動で再接続します（画面が一瞬切り替わります）。設定の「起動時に自動で再接続」をオフにすると、ホーム上部の「再接続」ボタンから手動で行えます。
- 同じメモを2台で同時に編集した場合は、後から保存した方が残ります。
- ドライブ上のデータは「アプリ専用の隠しフォルダ」に入るため、ドライブの一覧には表示されません（容量は「ドライブの設定 → アプリの管理」で確認・削除できます）。

## アプリを更新したいとき

GitHub のリポジトリで `index.html` を上書きアップロードするだけです。次回起動時に反映されます（反映されない場合はアプリを一度閉じて開き直してください）。

## 機能一覧

- タイムライン（すべて／アカウント別タブ、新しい順・古い順）
- 複数アカウント（アイコン・ヘッダー画像・自己紹介・フォロー／フォロワー数を自由に設定）、投稿ごとにアカウントを選択可
- 画像添付（最大4枚・自動圧縮）、画像ビューア・保存
- 返信（スレッド表示）、いいね・リポスト・ブックマーク・プロフィール固定
- 返信／リポスト／いいね／表示数を手動設定、またはプリセット（少なめ・ふつう・バズ）からランダム設定
- 投稿日時の指定（日記の後書きに）
- #ハッシュタグ・URL・@メンションのリンク、「あなたのトレンド」
- 検索、カレンダー、ストレージ（画像一覧）
- テーマ（ライト／ダークブルー／ブラック／端末に合わせる）、テーマカラー6色、文字サイズ
- エクスポート（テキスト・CSV・画像込みバックアップ）と復元
- ショートカット：投稿画面で Ctrl+Enter（Mac は ⌘+Enter）で投稿

## 困ったとき

- **「redirect_uri_mismatch」エラー**：Google Cloud に登録したリダイレクトURIが、アプリの設定画面に表示されているものと1文字でも違うと出ます（末尾の `/`、`http`/`https` に注意）。
- **「access_denied」／ アクセスがブロックされた**：手順2-5のテストユーザーに自分のアドレスを追加したか確認してください。
- **iPhone のホーム画面版で接続できない**：一度 Safari でアプリのURLを開いて接続できるか試してください。ホーム画面版とSafari版はデータの保存場所が別なので、使う方で接続してください。
